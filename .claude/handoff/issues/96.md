## What to build

The browser suite runs two real pages in one room and asserts they agree on the visible things: the same seats and names, the same ready flags, one countdown, the match screen on both, and one final board row for row. **Tick-by-tick agreement of the two simulations is not asserted.**

The comment in that test says this needs "a checksum the client does not expose, which is #41; building a feature in order to test it is the wrong order round." That was true when it was written. **#41 has since shipped** — the room carries a checksum function, the session installs it over the packed snapshot, the client already sends checksum messages on an interval, and the headless replay asserts on the same hash. The feature exists; only the assertion is missing.

Every desync finding in #81 is currently unprovable in CI for this reason, and this is the cheapest thing that changes that.
